4 · Damit es wirklich kostenlos bleibt

Für unbegrenzten Text ohne Tokenrechnung braucht es ein Modell, das lokal auf dem Gerät läuft. Deine installierte Plain-AI-App kann das bereits separat. Diese HTML-Demo kann aus Sicherheitsgründen nicht einfach auf deren internes Modell zugreifen. Der nächste echte Integrationsschritt wäre eine iOS-App mit offizieller lokaler Modell-Schnittstelle; das lässt sich nicht allein durch eine Safari-Webseite freischalten.

Demo V1 · Läuft lokal im Browser, ohne Konto und ohne externe API. Nachrichten werden von diesem Code nicht an einen Server gesendet. Kein echtes KI-Modell, kein echter Video-Avatar.
